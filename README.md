## Workflow-lite

[![License](https://img.shields.io/badge/License-Apache%202.0-green.svg)](https://github.com/sogou/workflow/blob/master/LICENSE)
[![Language](https://img.shields.io/badge/language-c++-red.svg)](https://en.cppreference.com/)

Workflow-lite is a simplified version of [Sogou C++ Workflow](https://github.com/sogou/workflow), removing all HTTP and other protocol-related code, retaining only workflow-related code, and limiting the export of certain symbols to avoid conflicts with other libraries. For specific usage instructions, please refer to the original project [Sogou C++ Workflow](https://github.com/sogou/workflow).
